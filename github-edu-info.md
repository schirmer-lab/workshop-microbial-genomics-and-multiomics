# GitHub Education Guide for TUM Master Students

*Last updated: September 2025*

## Overview

GitHub Education provides free access to premium development tools, including **GitHub Pro**, **GitHub Copilot Pro**, **GitHub Codespaces**, and access to the **Student Developer Pack** with 100+ partner tools worth thousands of dollars.

## What You Get

### Core GitHub Benefits
- **GitHub Pro account** (normally $4/month)
  - Unlimited private repositories
  - Advanced collaboration tools
  - 3,000 GitHub Actions minutes/month
  - 2 GB GitHub Packages storage
  - 180 GitHub Codespaces hours/month
  - 20 GB Codespaces storage

- **GitHub Copilot Pro** (normally $10/month)
  - AI-powered code suggestions in your editor
  - Context-aware programming assistance
  - Support for multiple programming languages
  - Integration with VS Code, JetBrains IDEs, and more

- **GitHub Codespaces Pro**
  - Cloud-based development environments
  - Pre-configured coding environments
  - Access from any device with internet

### Student Developer Pack
Access to 100+ tools and services including:
- **JetBrains** - Professional IDEs (IntelliJ IDEA, PyCharm, etc.)
- **Microsoft Azure** - $100 cloud credits + free services
- **DigitalOcean** - $200 platform credit
- **DataCamp** - 3 months free data science courses
- **MongoDB** - $50 Atlas credits + certifications
- **Educative** - 6 months of coding courses
- **Stripe** - Waived fees on first $1000 revenue
- And many more development, design, and productivity tools

## Eligibility Requirements

✅ **You qualify if you:**
- Are enrolled in a degree-granting program (✅ TUM Master's program)
- Have a verifiable academic email or student documentation
- Own a GitHub personal account
- Are at least 13 years old

## Application Process

### Step 1: Create GitHub Account
If you don't have one already:
1. Go to [github.com](https://github.com)
2. Sign up with your **TUM email address** (@mytum.de or @tum.de)
3. Verify your email address

### Step 2: Apply for GitHub Education
1. **Navigate to**: [github.com/settings/education/benefits](https://github.com/settings/education/benefits)
2. **Click**: "Start an application" under "GitHub Education"
3. **Fill out the application form** with:
   - Your TUM email address
   - School name: "Technical University of Munich" or "Technische Universität München"
   - Graduation year
   - How you plan to use GitHub

### Step 3: Provide Verification Documents
Upload **one** of the following as proof of enrollment:
- **Student ID card** with current enrollment date (recommended)
- **Current semester transcript**
- **Class schedule** for current semester
- **Enrollment certificate** (Immatrikulationsbescheinigung)
- **Official letter** from TUM confirming your student status

### Step 4: Wait for Approval
- Processing typically takes **1-7 days**
- You'll receive an email notification when approved
- Some applications may require additional verification

### Step 5: Access Your Benefits
Once approved:
1. Visit your [GitHub Education portal](https://github.com/education)
2. **Activate GitHub Copilot**: Go to Settings → Copilot to enable free Pro access
3. **Browse the Student Developer Pack**: Claim individual tool offers
4. **Set up Codespaces**: Start using cloud development environments

## Important Tips for TUM Students

### Using Your TUM Email
- **Always use your TUM email** (@mytum.de or @tum.de) for fastest verification
- If you used a personal email, you can add your TUM email in Settings → Emails

### Document Requirements
- **Student ID**: Take a clear photo showing your name, TUM logo, and valid dates
- **Transcript**: Download from TUMonline with current semester visible
- **Enrollment Certificate**: Get from TUMonline or Student Service Center

### Common Issues & Solutions
- **Application rejected**: Ensure documents clearly show current enrollment
- **Verification pending**: TUM is recognized globally, but processing may take longer for international students
- **Benefits not showing**: Check your [Education portal](https://github.com/education) after approval

## Maximizing Your Benefits

### For Course Projects
- Use **private repositories** for assignments and group work
- Leverage **GitHub Copilot** for coding assistance and learning
- Set up **Codespaces** for consistent development environments

### For Research & Thesis
- Store and version control your research code privately
- Use **GitHub Pages** for project documentation websites
- Collaborate with supervisors using GitHub's review tools

### Career Development
- Build a strong **GitHub profile** with your projects
- Use **DataCamp**, **Educative**, and **FrontendMasters** for skill development
- Practice coding interviews with **AlgoExpert** and **InterviewCake**

## Renewal & Duration

- **Duration**: Benefits last as long as you're enrolled as a student
- **Renewal**: Typically renews annually (you may need to re-verify)
- **Graduation**: You'll lose student benefits but keep your repositories and history
